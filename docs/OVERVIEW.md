# Visão Geral

Este projeto é uma aplicação **Vercel-first**, baseada em **FastAPI**, **Next.js** e **Vercel Postgres**.

## Stack
- Frontend: Next.js (Vercel)
- Backend: FastAPI (Serverless Functions)
- Banco: Vercel Postgres + pgvector
- Embeddings: OpenAI-compatible API
- Agendamentos: Vercel Cron

## Objetivo
Fornecer uma plataforma de pesquisa e análise baseada em agentes de IA, com arquitetura simples, escalável e sem dependência de AWS.
